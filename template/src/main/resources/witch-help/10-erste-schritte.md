# Erste Schritte

Willkommen! Diese Seite ist ein Beispiel für das Hilfesystem von witch-ui.

- Hilfeseiten sind Markdown-Dateien unter `src/main/resources/witch-help/`.
- Die Zahl vor dem Dateinamen bestimmt die Reihenfolge, der Rest die Adresse:
  `10-erste-schritte.md` → `hilfe/erste-schritte`.
- Die erste Überschrift ist der Titel im Inhaltsverzeichnis.
